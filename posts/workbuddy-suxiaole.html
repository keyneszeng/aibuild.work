苏乐：WorkBuddy 国产通用 Agent 实操教程

作者：苏乐（@ai_suxiaole，XWise 插件作者） · 发布：2026-07-02 · 查看原文 ↗
这是一篇面向小白的国产通用 Agent 上手长文。作者认为 Claude Code / Codex 虽强，但海外工具在注册、支付、安装上仍有门槛，很多人「用不上」；而 WorkBuddy 把国内用户最需要的办公自动化拼图补上了——日常七成以上的办公活它都能接。
📌 本文要点速览
  • 是什么：WorkBuddy 是腾讯出品的国产通用 Agent 客户端（Mac / Windows），对标 Claude Code / Codex 的「能操作你电脑干活的 AI 同事」。
  • 最大亮点：原生打通微信远程控制——手机小程序就能让它干活，海外 Agent 普遍做不到。
  • 作者实话：国产模型写复杂大工程仍有差距，小项目 / 小网页 / 小工具没问题；真上大工程仍建议 Claude Code 或 Codex。
  • 适合谁：不想折腾环境、不想硬啃开发流程，但想把汇报、数据、PPT、代码这些日常活自动化的人。

一、下载与安装

官网直接进 workbuddy.cn，Mac、Windows 两个版本都有，按自己系统下载。安装包下下来双击、一路默认，装完打开客户端即可。

门槛低是它相对海外工具的核心优势：不用翻墙注册、不用绑境外支付。

二、办公场景线：日常七成活它都能接

作者用一条「办公场景」主线串起最常用的四类活：

  • 写汇报：把要点 / 素材丢给它，生成结构化汇报草稿。
  • 理数据：整理一批杂乱数据、归类、出表格。
  • 出 PPT：从主题到成稿，产出可演示的幻灯片。
  • 改代码：小脚本、小工具级修改能接住（复杂工程另说）。

跟着走一遍流程，就能上手。作者强调：对绝大多数普通人，Agent 最大价值不是帮你写漂亮代码，而是把每天琐碎、重复、让人烦躁的办公任务自动化掉。

三、开发场景线：小项目能跑，大工程另有选择

WorkBuddy 也能做开发类任务——小网页、小工具、小项目没问题。但作者直言：

⚠️ 作者的诚实判断

国产模型在代码能力上离最顶尖那批（Claude Code / Codex 背后模型）还有差距。小东西够用；真上复杂大工程，依然强烈建议想办法用 Claude Code 或 Codex。「这话搁两年后会不会翻，我不知道，但眼下就是这样。」

四、自定义 Skill：把常用流程固化下来

可以挂自定义 Skill。作者举例：他挂了一个「服务器管理」Skill，之后只要跟 WorkBuddy 说「用我那个服务器 Skill 把这个网页部署上线」，它就会照办——把重复操作固化成一句话指令。

五、远程控制：不在电脑前也能让它干活（最大的差异化）

因为是腾讯自家产品，WorkBuddy 的远程控制原生打通了微信，这是很多海外 Agent 想做都做不到的一点。

配置步骤

  1. 打开左侧功能区里的「助理」。
  2. 点「设置」。
  3. 把里面两个开关打开。
  4. 掏出手机，微信扫码，进入小程序授权登录。
  5. 客户端左上角出现「已连接」字样，就 OK。

手机端两种模式

  • 云端工作：任务在云端沙箱跑，电脑关着都行。
  • 连接电脑：远程操控你本地这台机器干活，适合需要读本地文件的任务。

真实场景：人在外面被催「把电脑里某份文件发给财务」，以前只能赶回去，现在手机小程序里说一声就完事（前提是提前配好对应连接器；没配也能让文件先进小程序对话框，再手动转发）。

除了小程序，微信里还能挂 ClawBot 插件做入口——作者个人体验小程序更稳定顺手，微信插件是备选。飞书、钉钉、QQ 也都能接助理，按页面提示走即可。

六、写在最后

作者一贯观点：对普通人，Agent 的价值是把每天琐碎重复的办公任务自动化——发一封邮件、整理一批数据、出一份 PPT、跑一个小站。这些活加起来，才是「AI 真正让生活变轻」的部分。WorkBuddy 现在把这几件事都接住了，而且做得挺体面。

写 Claude Code / Codex 教程时，最扎心的评论永远是「好是好，用不了」。这篇，算是把那块缺的拼图补上了。

🛡️ 阅读时的安全提醒（与课程体系红线一致）
  • 让 Agent 碰本地文件 / 发邮件前，确认它只访问你授权的范围；敏感文件先脱敏。
  • 涉及公司数据、客户信息、密钥，不要无脑交给任何 AI 工具——人判断、AI 辅助。
  • 远程控制（微信 / 小程序）开启后，注意授权范围，避免 Agent 越权操作。
