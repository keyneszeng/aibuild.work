# 第 10 课  Prompt 模板库（可直接复制使用）

> 汇总本营所有可复制 Prompt，按任务分类。复制后把【括号】内容换成你的真实信息即可。
> 通用原则：角色 + 背景 + 任务 + 输出格式 + 限制条件 + "信息够就直接做，不够先问我 3 个问题"。

---

## A. 通用标准结构（所有场景底座）

```
你现在扮演： [角色]
我的背景是： [我是谁、在做什么]
我要完成的任务是： [一句话]
目标对象/读者是： [谁]
已有材料如下：
【粘贴你的材料】
请你输出： [明确要什么]
输出格式： [列表/表格/三段式]
限制条件： [字数、语气、不能编数字等]
请先问我 3 个关键问题，如果信息足够，再直接开始。
```

---

## B. 写作与文档

**B1 通知**
```
你是行政，写一则正式通知：
时间[ ]、地点[ ]、议题[ ]、参会人[ ]。
语气正式，含标题/时间地点/议程/落款。
```

**B2 周报**
```
你是[我的岗位]，帮我写本周周报。
本周做了：[列 3-5 件事]
请按【本周完成 / 进行中 / 下周计划 / 需协调】四段输出，每点不超过 2 行。
```

**B3 工作方案**
```
你是[岗位]，写一份[主题]方案草稿。
背景：[ ] 目标：[ ] 约束：[ ]
按【背景/目标/步骤/风险/所需资源】输出。
```

## C. 会议与沟通

**C1 会议纪要**
```
把以下会议记录整理成表格，列：【决议 / 待办 / 负责人 / 截止时间】。
只基于原文，不要补充原文没有的内容。
【粘贴转录文本】
```

**C2 跟进清单**
```
从以下会议/聊天记录中，提取所有"需要我后续跟进"的事项，
按【事项 / 关联人 / 建议下一步 / 优先级】列表。
```

## D. 销售与客服

**D1 破冰话术（Few-shot）**
```
你是资深销售。参考下面这段我真实的赢单话术（脱敏）：
【贴一段你的话术】
按同样语气和逻辑，写一段新的破冰话术，对象：[客户类型]，阶段：[首次加微/复聊]。
```

**D2 异议四步**
```
客户说"[太贵了/再想想/竞品更便宜]"。
请按四步生成回复：①共情 ②澄清 ③举证（用我提供的真实案例[ ]）④推进。
涉及价格/政策的具体数字用"[待我确认]"占位，不要编造。
```

**D3 客服基于资料答（RAG）**
```
你是我方客服助理，只依据下面《资料》回答，资料没有的就说"我帮您确认后回复"。
《资料》：【粘贴 FAQ/制度】
客户问题：[ ]
```

## E. 内容与运营

**E1 选题库**
```
你是[平台]内容运营，围绕"[领域]"生成 20 个选题角度，
覆盖：干货、痛点、案例、对比、趋势五类，每条一句话。
```

**E2 多版文案**
```
把以下产品卖点写成：①小红书种草文 ②朋友圈短文案 ③短视频口播稿。
卖点：[ ] 注意：不夸大功效、不违反广告法。
```

**E3 数据洞察**
```
你是经营分析助理，分析下面这张表，按【总体趋势/3个异常点/3个建议动作】输出，
数字必须来自原表，不确定处标"[需我核对]"。
【粘贴表格】
```

## F. 管理与人事

**F1 JD**
```
你是资深 HR，我要招[岗位]，核心职责：[3-5条]，我们要这样的人：[特质]。
输出 JD：【岗位职责/任职要求/加分项/我们提供】，不出现歧视性表述，薪资只写我提供的。
```

**F2 复盘**
```
把以下复盘内容整理成表格：【问题 / 根因(待我确认) / 改进动作 / 负责人(待我填)】。
【粘贴记录】
```

---

> 复制即用。每条都留了"人把关"的钩子（[待我确认]/[需我核对]/[待我填]），这是本营红线。
