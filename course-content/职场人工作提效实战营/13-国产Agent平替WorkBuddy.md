# 第 13 课  国产 Agent 平替：用 WorkBuddy 接住日常七成活

## 一、教学目标

- **知识**：知道 WorkBuddy 是什么（腾讯出品的国产通用 Agent）、它和 Claude Code / Codex 的关系、为什么它对"用不上海外工具"的人是关键的拼图。
- **能力**：用 WorkBuddy 完成汇报 / 数据 / PPT / 代码四类办公活，并配好微信远程控制，把常用流程固化成自定义 Skill。
- **作品**：跑通一个真实办公任务 + 配置好微信远程控制（"已连接"状态）。

## 二、开场问题

> 上节课学了 Codex，但有人卡在注册、支付、安装——"好是好，用不了"。
> 你身边是不是也有人（或者你自己）被海外工具的门槛挡住了？
> 这节课给你一个**国内能直接装、能直接用**的平替，把最日常的办公活自动化掉。

## 三、核心概念

### 1. WorkBuddy 是什么（一句话版）

腾讯出品的**国产通用 Agent 客户端**（Mac / Windows 都有），本质也是"能操作你电脑干活的 AI 同事"。
它最大的好处是**门槛低**——不用翻墙注册、不用绑境外支付、双击默认装完就能用。

### 2. 它和 Claude Code / Codex 的关系：互补，不是替代

- Codex / Claude Code：能力强，但海外工具在注册、支付、安装上仍有门槛，很多人"用不上"。
- WorkBuddy：把国内用户最需要的**办公自动化拼图**补上了——日常七成以上的办公活它都能接。
- 两者可以并存：海外工具啃复杂工程，国产 Agent 接日常琐碎。

### 3. 最大亮点：原生打通微信远程控制

因为是腾讯自家产品，WorkBuddy 的远程控制**原生打通了微信**——手机小程序就能让它干活。
这是很多海外 Agent 想做都做不到的一点（后面第六节细讲）。

### 4. 作者的一条诚实判断（务必记住）

国产模型在**代码能力**上离最顶尖那批（Claude Code / Codex 背后模型）还有差距：
- ✅ 小项目、小网页、小工具：没问题，能接住。
- ⚠️ 真上**复杂大工程**：仍强烈建议想办法用 Claude Code 或 Codex。

> 这句话搁两年后会不会翻，作者说"不知道，但眼下就是这样"。我们照当下事实用就好。

## 四、真实工作场景案例演示

### 案例 1：汇报地狱
**场景**：每周要写结构化汇报，素材散、格式烦。
**做法**：把要点 / 素材丢给 WorkBuddy，让它生成结构化汇报草稿，你只改口径和数字。

### 案例 2：数据整理
**场景**：一批杂乱数据要归类、出表格。
**做法**：贴进去，让它归类、清洗、输出表。

### 案例 3：PPT 产出
**场景**：从主题到成稿要耗一下午。
**做法**：给它主题和要点，产出可演示的幻灯片初稿。

### 案例 4：人在外面被催"发文件"
**场景**：不在电脑前，突然被催"把电脑里某份文件发给财务"。
**做法**：手机微信小程序里跟它说一声，让它操作本地电脑把文件发走（前提：提前配好对应连接器；没配也能先扔进小程序对话框再手动转发）。
**红线提醒**：远程控制开启后，注意授权范围，避免 Agent 越权操作；敏感文件先脱敏。

## 五、标准工作流（照着做，5 步）

1. **安装**：进 `workbuddy.cn`，按自己系统下 Mac / Windows 版，双击一路默认装完打开。
2. **定任务**：选一件办公活（汇报 / 数据 / PPT / 代码）。
3. **下指令**：说清楚"要什么结果"（参考第 12 课"读 X、做 Y、输出 Z"句式）。
4. **人审 + 核对**：AI 生成后你打开看一眼，关键数字 / 人名自己核。
5. **固化**：常用流程挂成**自定义 Skill**，以后一句话就能复用（比如"用我那个服务器 Skill 把这个网页部署上线"）。

## 六、微信远程控制配置（它最差异化的地方）

配置步骤：
1. 打开左侧功能区里的「助理」。
2. 点「设置」。
3. 把里面两个开关打开。
4. 掏出手机，微信扫码，进入小程序授权登录。
5. 客户端左上角出现"已连接"字样，就 OK。

手机端两种模式：
- **云端工作**：任务在云端沙箱跑，电脑关着都行。
- **连接电脑**：远程操控你本地这台机器干活，适合需要读本地文件的任务。

> 除了小程序，微信里还能挂 ClawBot 插件做入口——作者体验小程序更稳定顺手，微信插件是备选。飞书、钉钉、QQ 也都能接助理，按页面提示走即可。

## 七、红线总提醒（务必遵守）

- 让 Agent 碰本地文件 / 发邮件前，确认它只访问你**授权的范围**；敏感文件先脱敏。
- 涉及**公司数据、客户信息、密钥**，不要无脑交给任何 AI 工具——人判断、AI 辅助。
- 远程控制（微信 / 小程序）开启后，注意授权范围，避免 Agent 越权操作。
- AI 生成内容**可能出错**：关键结果自己核对；复杂工程优先用更强的海外工具。
- WorkBuddy 更新很快（功能、入口、价格都可能变），以官网 `workbuddy.cn` 和客户端实际显示为准。

## 八、课后小任务

挑你工作里**一件日常办公活**（汇报 / 数据 / PPT / 小工具任一），用 WorkBuddy 跑通它；并顺手把微信远程控制配好，体验一次"不在电脑前也能让它干活"。
