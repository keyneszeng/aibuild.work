# 第 12 课  用 Codex 写代码做工具 —— 不会写代码，也能让 AI 帮你造个小应用

## 一、教学目标

- **知识**：知道 Codex 是什么、有哪几种用法（App / CLI / IDE 扩展 / Web）；理解"编码智能体"和"聊天 AI"的区别。
- **能力**：用大白话给 Codex 下指令，做出一个能用的小工具（比如把一堆聊天记录转成表格、把报销单自动汇总）。
- **作品**：跑通一个真实小项目，产出《我的第一个 AI 小工具》成品 + 一句能复用的需求描述。

## 二、开场问题

> 你工作里有没有这种事：要重复处理同一种文件——把 50 条客户留言整理成表、把每月发票合并成一个 Excel、把一堆截图里的文字抠出来？
> 这些事"写个程序"最省事，但你不会写代码。
> 这节课，你就用 Codex 把这件事办了——**你动嘴，它动手**。

## 三、核心概念

### 1. Codex 是什么（一句话版）

Codex 是 OpenAI 出品的**编码智能体**：你用自然语言说"我要做个啥"，它自己写代码、建文件、跑起来、还帮你改 bug。
它不是聊天机器人，而是**会操作你电脑里文件的"编程同事"**。

橙皮书里把它分成四种形态：

| 形态 | 入口 | 适合你吗 |
|---|---|---|
| **Codex App（桌面）** | 装个软件，选个文件夹就能用 | ⭐ 最推荐，新手最顺手、功能最全 |
| **Codex CLI** | 终端命令行 | 想进阶、爱折腾可用 |
| **Codex IDE 扩展** | VS Code / Cursor 里 | 本身就在写代码的人 |
| **Codex Web（云端）** | 网页 chatgpt.com/codex | 不想装软件、临时用 |

### 2. 它和普通聊天 AI 的区别

- 聊天 AI（ChatGPT 对话框）：**给你答案文字**，你还得自己复制粘贴去干活。
- Codex：**直接改你文件夹里的真实文件**，生成的是能跑的程序/网页，不是一段建议你照做的文本。

### 3. 三种用法姿势（摘自橙皮书）

- **对话式**：打开 App，聊天一样说需求，它边问边做。
- **单次任务**：一句指令搞定，比如"把这个 CSV 按客户名拆成 12 个表"。
- **文件夹工作模式**：选好一个项目目录，Codex 能读里面的所有文件、统一改写——这是干真实工作的主战场。

### 4. 最关键心法：把"想要的结果"说清楚

不要说"帮我做个工具"。要说：
> "读取 `客户留言.txt`，每行是一条留言，提取【客户名、问题、情绪、是否紧急】四列，输出 `result.csv`，并在最前面加一行统计总数。"

**结果越具体，它做出来的越能用。**

## 四、真实工作场景案例演示

### 案例 1：销售的"客户留言 → 表格"噩梦
**场景**：每天收到几十条微信客户留言，要整理成跟进表，手工 1 小时。
**Codex 做法**：把所有留言贴进一个 `txt`，对 Codex 说"提取客户名/需求/紧急度，输出 Excel"。1 分钟出表，销售只核对人名。
**红线提醒**：客户姓名、电话是 PII（个人敏感信息）——**别把真实数据传出去练手**，先用假数据测试，确认工具好用再在本地副本跑真数据。

### 案例 2：行政的"发票合并"
**场景**：每月 30 张报销发票散在不同文件，要合成一张总表。
**Codex 做法**：把发票图片/PDF 放一个文件夹，让它"识别每张的金额、日期、类别，合并成 `汇总.xlsx`"。
**红线提醒**：发票含公司财务信息，**只在自己电脑本地跑，别用任何云端模式把文件传外网**。

### 案例 3：运营的"海报生成器"
**场景**：每周要出 5 张活动海报，排版重复。
**Codex 做法**：让它写个网页小工具，填文字自动出图——这就是橙皮书第五篇"做网站/视频"的思路。

## 五、标准工作流（照着做）

橙皮书第四篇给了一条"需求 → 交付"链路，职场人版精简成 5 步：

1. **定结果**：先想清楚"我要一个什么样的文件/网页出来"。
2. **备原料**：把要处理的文件放进一个**专门文件夹**（别混进重要项目）。
3. **下指令**：用"读 X、做 Y、输出 Z"的句式说需求。
4. **看成品 + 人审**：AI 生成后，**你打开看一眼对不对**，数字/人名必须亲自核。
5. **迭代**：不对就说"把第 3 列改成按金额排序"，它会接着改。

## 六、红线总提醒（务必遵守）

- 不把**公司涉密源码、客户 PII、未公开数据、密钥/Token** 喂给 Codex 或任何 AI。
- AI 写的代码**可能出错**：人来判断、AI 辅助，关键结果自己核对。
- 先在**副本/专门测试文件夹**里跑，确认安全再碰真数据。
- Codex 更新很快（安装方式、模型名、入口都可能变），具体以 OpenAI 官方文档和你账号实际显示为准。

## 七、课后小任务

挑你工作里**一件重复处理文件的事**，用 Codex App 做一个小工具跑通它。把"你下的那句指令"记下来，这就是你第一个可复用的 Prompt。
