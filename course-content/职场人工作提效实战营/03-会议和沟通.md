# 第 3 课  会议和沟通 → 会议纪要 + 跟进清单

## 一、教学目标

- **知识**：理解"会议纪要"的本质不是"记下来"，而是"把发生的事变成要做的事"；掌握"信息抽取 / 文本摘要 / 语气改写"三种 AI 能力分别对应开会前、中、后的哪个环节；知道为什么"责任人 + 截止时间"是纪要里最不能省的两栏。
- **能力**：把一段杂乱的会议录音文字、聊天记录或对方邮件，整理成结构清晰、可直接转发的纪要或回复；会用"给样例（Few-shot）"让 AI 模仿你公司既有的纪要风格。
- **作品**：一份《标准会议纪要模板》+ 一份《跨部门的清晰沟通回复》，本周开会就能用。

> 本课方法参考 Prompt-Engineering-Guide 的「Text Summarization（文本摘要）」「Information Extraction（信息抽取）」「Prompt Elements（指令 / 上下文 / 输入 / 输出指示 / 示例）」等真实框架——我们把它翻译成职场人能直接用的动作。

## 二、开场问题

> 上周的会，你记下了几条？散会后，有几件事真的有人跟进、按时完成？
> 有没有过这种经历：对方发来一段 300 字、没分段、重点藏在第三行的微信/邮件，你看了两遍还是不知道"他到底要我干什么"？

大多数职场人不是"不会开会"，是"开完会就丢了"——记不全、理不清、传不准。这一课，AI 帮你做三件事：**会前想清楚要谈什么、会中/会后把话变成清单、对外沟通把含糊变成清楚**。

## 三、核心概念

### 1. 会议纪要 = 信息抽取（Information Extraction）
开会最值钱的产出不是"谁说了啥"，而是"谁、在什么时候前、要交什么"。这正好是 AI 擅长的"信息抽取"：你给它一段原文，它帮你在里面找出"决策 / 待办 / 责任人 / 截止时间 / 风险"这几类要素，列成表。你再加一道人工核对——人名对不对、时间有没有写错。

### 2. 三种会议，三种 AI 用法
- **有录音/转写文字的会**（最常见）：把转写文字贴给 AI，让它输出"决议 + 行动项表"。
- **只有零散聊天的会**（微信群、钉钉）：把聊天记录贴给 AI，让它归纳"达成的共识"和"待办"。
- **纯脑内准备**：会前让 AI 帮你列"本次会议要确认的 5 个问题"，你带着清单去开，效率翻倍。

### 3. 结构化纪要的"黄金五栏"
一份能落地的纪要至少要有五栏：**事项 / 负责人 / 截止时间 / 当前状态 / 风险或需协调**。其中"负责人"和"截止时间"最不能省——没有这两栏的纪要，等于没开。

### 4. 对外沟通 = 语气改写（Tone Rewriting）
把对方含糊的话、你心里想说但怕得罪人的话，交给 AI 改写成"清楚、得体、不背锅"的版本。这是"指令 + 读者"的组合拳：你告诉 AI 读者是谁、想要什么语气，它就能拆掉你话里的刺。

### 5. 给样例（Few-shot）模仿你的风格
每个公司纪要风格不同。把一份你上司满意的旧纪要做样例贴给 AI，说"按这个风格写"，产出会贴你口味得多。这叫 few-shot（给样例提示），比从零描述风格更准。

## 四、真实工作场景案例演示

### 案例 1：周会纪要从"流水账"到"行动表"
**原始材料**（转写文字节选）："上周那个客户跟进还没弄完，小王说这周搞，然后那个海报也迟迟没出，设计那边说要等素材，还有下个月预算得提前报……"
**AI 做法**：贴入文字，要求"抽取行动项，按 事项/负责人/截止/状态 四栏输出"。
**输出样例**：
| 事项 | 负责人 | 截止 | 状态 |
|---|---|---|---|
| 客户跟进收尾 | 小王 | 本周五 | 进行中 |
| 海报出图 | 设计（待素材） | 本周三 | 阻塞：等素材 |
| 下月预算上报 | 我 | 本月25日 | 待启动 |
**人工核对**：确认"小王""设计"是正确人名/角色，截止时间与你记忆一致后再发群。

### 案例 2：把含糊的对方邮件改写成清晰回复
**对方原话**："那个事儿你们看怎么弄吧，反正尽快，对了之前说的费用也不太对。"
**AI 做法**："帮我把这封回复改写成专业、不含糊、能推动对方的版本，并列出我需要向对方确认的 2 个问题。"
**输出样例**："关于项目推进，我们建议本周三前确认方案 A/B 二选一；另需您确认两点：（1）费用差异具体指哪一笔？（2）'尽快'是否指本周内？确认后我们立即启动。"
**人工把关**：费用金额、方案名称必须你填真实信息，AI 不编数字。

### 案例 3：向上汇报"领导 3 分钟能看懂"
**痛点**：你手上 8 件事，领导只想知道"进度到哪、有没有卡点、要我干什么"。
**AI 做法**：把杂乱进展贴入，要求"重写为'结论先行 + 3 个要点 + 1 个求助'，每点一句话"。
**红线**：含未公开业绩/人事变动，只对内，不外发。

## 五、动手任务

- **背景**：你是[岗位]，本周至少有 1 次会 / 1 次跨部门的文字沟通。
- **输入**：一段会议转写文字或一段对方发来的含糊消息（请脱敏，用"某客户/小王"代替真名）。
- **步骤**：
  1. 用下面"纪要模板"生成一份结构化行动表。
  2. 用"沟通回复模板"把一段含糊消息改写成清晰回复。
  3. 各做 1 次迭代："语气再正式点""把截止时间加粗"。
  4. 人工核对人名、时间、金额。
- **预期输出**：纪要 1 份 + 沟通回复 1 份。

### 本课 Prompt 模板（标准结构）

**会议纪要模板**
```
你现在扮演：一位资深行政/项目助理，擅长把会议录音整理成可落地的行动清单
我的背景是：我是[岗位]，刚开完[周会/项目会/跨部门会]，手上有转写文字但不想自己逐条整理
我要完成的任务是：把会议内容整理成结构化工件
目标用户/读者是：[参会同事 / 我的领导]
已有材料如下：[粘贴转写文字或聊天记录，已脱敏]
请你输出：① 一句话会议结论；② 行动项表，列 事项/负责人/截止时间/状态/风险；③ 需升级给领导决策的事项
输出格式：Markdown，先结论后表格
限制条件：不编造人名与时间；人名用[待确认]占位若原文不清；不出现真实客户名电话
请先问我 3 个关键问题，如果信息足够，再直接开始。
请输出可直接用于工作场景的版本，并附检查清单
```

**沟通回复模板**
```
你现在扮演：一位沟通得体、推动事情解决的职场同事
我的背景是：对方发来一段含糊的消息[粘贴]，我需要回复但不想显得含糊或推诿
我要完成的任务是：把我的回复改写成清楚、专业、能推动对方给明确信息的版本
目标用户/读者是：[对方角色，如客户/合作方/上级]
已有材料如下：[对方原话] + [我想达成的结果]
请你输出：① 改写后的回复全文；② 我需要向对方确认的 2-3 个关键问题清单
输出格式：回复正文 + 问题清单两段
限制条件：不编造费用/时间等事实；语气[专业/亲切]；不暴露内部机密
请先问我 3 个关键问题，如果信息足够，再直接开始。
请输出可直接用于工作场景的版本，并附检查清单
```

## 六、人工检查清单

- [ ] 纪要里每个"负责人"都是真实存在的人/角色，没有 AI 凭空安名字。
- [ ] 每个"截止时间"与我的记忆或日历一致，没有 AI 乱编日期。
- [ ] 行动项表我真的打算发出去跟进，不是做完作业就丢。
- [ ] 沟通回复里的费用、方案名、时间点是我填的真实信息。
- [ ] 含未公开信息的纪要只对内发，没有误发外部群。

## 七、常见错误

1. **把 AI 当录音笔**：以为贴进去就全自动。AI 做的是"整理"，原始转写可能漏字，关键结论你要补。
2. **漏了负责人/时间**：纪要只有"要做 X"，没人认领、没 deadline，等于没写。
3. **照搬不改语气**：AI 给的回复太生硬/太软，不贴合你和对方的关系，发出去反而尴尬。
4. **忘记脱敏**：把含客户真名的聊天记录丢进公开 AI 做纪要。
5. **不迭代**：第一版格式不顺眼就重来；其实说一句"加一列风险栏"比重写快十倍。

## 八、课后作业（明确提交物）

**提交物**：① 一份真实或模拟会议的《结构化纪要》（含结论 + 行动表 + 升级事项）；② 一段《跨部门清晰回复》（针对一段含糊消息）。可用模拟数据，但结构完整、关键事实有"[待确认]"标注。

## 九、评分标准

| 维度 | 满分 | 说明 |
|---|---|---|
| 完成度 | 25 | 纪要 + 回复两份齐全，结构完整 |
| 质量 | 25 | 五栏齐全、结论先行、语气得体 |
| 独立思考 | 25 | 结合自身岗位调整，非照搬案例 |
| 实用性 | 25 | 模板本周开会能直接复用 |

---

> **红线回顾**：人名、时间、金额由你核对；客户/内部机密不进公开 AI；AI 给的是草稿，发出去前你过一遍。
