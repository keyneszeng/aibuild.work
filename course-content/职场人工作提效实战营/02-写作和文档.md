# 第 2 课  写作和文档 → 通知 / 周报 / 方案模板

## 一、教学目标

- **知识**：掌握"角色 + 背景 + 读者 + 格式 + 限制"的写法；理解"先搭骨架再填肉"比"一口气写完"更稳。
- **能力**：用 AI 生成三类高频文档（通知、周报、方案）的初稿，并会按岗位语气改写。
- **作品**：一套可直接复用的《通知 / 周报 / 方案》三件套模板。

## 二、开场问题

> 上一次你写周报， staring at 空白文档超过 10 分钟吗？
> 你发出去的通知，有没有被人回"没看懂 / 漏了时间"？

写作难的不是"不会写"，是"不知道从哪下笔、写多正式、写多长"。本课给你三个"填空模板"。

## 三、核心概念

### 1. 好 Prompt 写文档的五个零件
参考 Prompt-Engineering-Guide 的"Prompt Elements"：指令、上下文、输入数据、输出指示、示例。落到职场人身上就是：
- **角色**：让 AI 像"资深行政/销售主管"一样写。
- **背景**：你的公司/事由/时间点。
- **读者**：写给谁看（决定语气）。
- **格式**：几段、几点、表格还是 bullet。
- **限制**：字数、不能编造、必须包含某信息。

### 2. 零样本 vs 给样例（Few-shot）
- **零样本**：直接说要求，适合通用文书。
- **给样例**：你贴一段"以前写得好的周报"，让 AI 模仿你的风格——这叫 few-shot，效果更贴你口味。

### 3. 迭代优化
第一版不满意？别重写，直接说："语气再正式点""删掉第 2 点""加一句风险提示"。AI 改比人快。

## 四、真实工作场景案例演示

### 案例 1：临时停水通知
**输入**："明天 9-11 点维修停水，提醒大家接水。"
**AI 初稿**：分"事由 / 时间 / 建议 / 联系人"四段，加 emoji 标题。
**人工核对**：确认时间、楼栋号无误后发出。

### 案例 2：周报从"流水账"到"有重点"
**痛点**：写一堆"做了啥"，领导嫌没重点。
**AI 做法**：把本周事项贴给 AI，要求"按 成果 / 进行中 / 风险与求助 三部分重写，每条一句话"。
**红线**：周报含未公开业绩，只对内用，别外发。

### 案例 3：给客户的合作方案框架
**输入**：产品卖点 + 客户行业。
**AI 输出**：背景 / 痛点 / 我们的方案 / 预期收益 / 下一步，五段式。
**人工把关**：收益数字必须你填真实数据，AI 不许编。

## 五、动手任务

- **背景**：你是[岗位]，本周要发 1 条通知 + 写 1 份周报 + 准备 1 份小方案。
- **输入**：真实或模拟的工作材料（请脱敏）。
- **步骤**：
  1. 用下面 3 个模板分别生成初稿。
  2. 各做 1 次迭代修改（语气/删减/补充）。
  3. 人工核对关键事实。
- **预期输出**：通知、周报、方案各 1 份成品。

### 本课 Prompt 模板（标准结构，三选一复制）

**通知模板**
```
你现在扮演：一位表达清晰、语气得体的行政同事
我的背景是：[公司/部门]将于[时间]进行[事项]，需要通知相关同事
我要完成的任务是：写一则内部通知
目标用户/读者是：[哪些人]（如：全体住客 / 项目群成员）
已有材料如下：[停水/会议/放假等关键信息]
请你输出：一则通知，包含 事由 / 时间地点 / 需要对方做什么 / 联系人
输出格式：分段清晰，标题加粗，不超过 200 字
限制条件：不编造时间地点；语气[正式/亲切]；不出现真实姓名电话
请先问我 3 个关键问题，如果信息足够，再直接开始。
请输出可直接用于工作场景的版本，并附检查清单
```

**周报模板**
```
你现在扮演：我的周报搭档
我的背景是：我是[岗位]，本周工作如下[贴事项]
我要完成的任务是：把流水账整理成有重点的周报
目标用户/读者是：我的直属领导
已有材料如下：[本周做的事，脱敏]
请你输出：周报，分 本周成果 / 进行中 / 风险与需协调 三部分，每点一句话
输出格式：Markdown，每部分 3 条左右
限制条件：不夸大、不编造数据；未公开业绩仅对内
请先问我 3 个关键问题，如果信息足够，再直接开始。
请输出可直接用于工作场景的版本，并附检查清单
```

**方案模板**
```
你现在扮演：一位有 10 年经验的[行业]方案顾问
我的背景是：我们提供[产品/服务]，目标客户是[客户类型]
我要完成的任务是：写一份给客户的初步合作方案框架
目标用户/读者是：潜在客户决策人
已有材料如下：[我们的卖点]、[客户痛点]
请你输出：方案，含 背景与痛点 / 我们的方案 / 预期收益 / 合作步骤 / 下一步
输出格式：五段式，每段小标题
限制条件：收益数字用[待填]占位，绝不编造；不出现竞品机密
请先问我 3 个关键问题，如果信息足够，再直接开始。
请输出可直接用于工作场景的版本，并附检查清单
```

## 六、人工检查清单

- [ ] 通知的时间、地点、联系人我已核实。
- [ ] 周报数据真实，未夸大，未外泄未公开业绩。
- [ ] 方案里的收益/报价是"待填"占位，没有 AI 编造的数字。
- [ ] 语气符合读者（对领导 vs 对群友不同）。
- [ ] 三份都做了至少一次迭代修改，不是直接复制初稿。

## 七、常见错误

1. **读者不分**：用"群聊语气"写周报给领导。
2. **让 AI 编数字**：方案收益直接编个"提升 30%"。必须你自己给数。
3. **一次要太长**：让 AI 写 2000 字方案，结果空。先框架后填充。
4. **不迭代**：初稿不顺眼就放弃。说一句"再简练点"往往就通了。
5. **忘脱敏**：把真实客户名写进练习 Prompt 发到公开 AI。

## 八、课后作业（明确提交物）

**提交物**：《通知+周报+方案》三件套各 1 份（可模拟数据，但结构完整、语气正确、关键事实有标注）。

## 九、评分标准

| 维度 | 满分 | 说明 |
|---|---|---|
| 完成度 | 25 | 三件套齐全 |
| 质量 | 25 | 结构清晰、语气贴合读者 |
| 独立思考 | 25 | 依据自身岗位调整，非照搬 |
| 实用性 | 25 | 模板可下周直接复用 |

---

> **红线回顾**：数字、报价、业绩由你提供，AI 只搭框架；机密数据不外传。
