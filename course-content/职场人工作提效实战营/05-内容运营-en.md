# Lesson 5 · Content Operations → Topic Selection / Copy / Short-Video Script

## I. Learning Goals

- **Knowledge**: Understand that "content production" can be broken into four steps — topic selection → headline → body → rewrite-for-distribution — and AI can lend a hand at each; master "multi-angle brainstorming" and "imitate a hit example's style (Few-shot)"; know why AI-written content must pass "originality check + no exaggerated efficacy," or you cross the advertising-law red line.
- **Skill**: Produce 20 topic angles, multiple headline versions, one body draft, and one short-video script framework at once; rewrite one long article into three distribution drafts with different tones for Moments / Weibo / Xiaohongshu.
- **Output**: A "This Week's Topic Library (≥20 items)" + 1 "Multi-version Copy" + 1 "Short-Video Script Framework."

> This lesson's methods reference Prompt-Engineering-Guide's "Creativity," "Few-shot (style imitation)," "Text Summarization (condensing)," and "Prompt Chaining" — breaking a big task into multiple steps, feeding each step's result into the next.

## II. Warm-up Question

> This week you need to post 3 articles; you stared at a blank doc half a day for a headline, and the one you finally posted got single-digit reads?
> A short-video script — you have the scene in your head but can't write the shot list, so it sat a week unwritten?
> Same piece of solid content posted on WeChat official account — should you tweak it before posting to Moments? Do you usually "copy-paste" or "can't be bothered to post a second time"?

The pain of content operations isn't "nothing to write," but "can't think of it, can't write fast, posted with no splash." AI doesn't invent creativity for you; it gives you **a whole table of candidates**, and you pick the best.

## III. Core Concepts

### 1. Four content steps, AI can help at each

- **Topic selection**: Give AI your product / niche / target audience, and it gives 20 angles at once (emotion / substance / controversy / story / comparison).
- **Headline**: Generate 10 headlines for the same theme, categorized as "suspense / number / pain-point / identity," and you pick.
- **Body**: Give it a skeleton to expand, or a first draft to retone.
- **Distribution rewrite**: Rewrite the same content into official-account / Moments / short-video-narration versions, saving you a rewrite.

### 2. Multi-angle brainstorming: don't ask for one, ask for a dozen

"Give me 3 headlines" is worse than "give me 20, covering 5 styles." AI excels at volume; you excel at picking. The essence of creative work is "cast wide, then select" — exactly the human-AI division.

### 3. Imitate a hit example (Few-shot)

Paste your single highest-read article to AI and say "in this opening style and rhythm, write 3 new ones." AI learns your "hit DNA," fitting your fans' taste better than writing from scratch.

### 4. Prompt Chaining: do long content step by step

Don't ask for a "complete video" at once for a short-video script. First have AI give "3 topics" → you pick 1 → have it give a "shot-list script (visual / narration / duration)" → then have it write "headline and cover copy." Feed each step to the next; quality beats one-shot.

### 5. Red line: original, no exaggeration, no copying

AI may "stitch together" existing online content. Before publishing you must do an **originality check**: are the core views yours / your team's; do the data have sources; do the efficacy claims cross "absolute language" (best / #1 / 100% effective) — that's an advertising-law minefield. What AI writes isn't automatically publishable.

## IV. Real Work Scenario Demo

### Case 1: Topic library from 0 to 20 in a week

**Input**: "We do workplace Excel training; target users are admin/finance beginners."
**AI output** (excerpt): ① "These 3 Excel shortcuts make the admin girl faster the same day" ② "Finance month-end reconciliation — save 2 hours with this trick" ③ "The table the boss wants is actually solved by 1 formula"… 20 items total, tagged "substance / emotion / story" type.
**Human pick**: Choose 3 for this week, the rest go into the topic pool.

### Case 2: Same substance rewritten for three platforms

**Original**: An 800-word "reconciliation speed-up" piece.
**AI distribution**: Official-account version (structured long-form) / Moments version (colloquial + emoji + question hook) / Xiaohongshu version (list format + cover title "finance sisters must save").
**Red line**: Data real, no exaggerated words like "10x faster."

### Case 3: Short-video script framework

**Input**: "Explain the point 'don't write weekly reports as a running log,' 30 seconds."
**AI output**: Shot list — 0–5s pain hook "your boss doesn't read your weekly report?"; 5–20s three tricks (conclusion first / chunking / write the ask); 20–30s call-to-action "comment '1' to get the template."
**Human**: Read the narration through yourself; don't read it like a robot.

## V. Hands-on Task

- **Background**: You are an [operator / sole proprietor], producing content this week.
- **Input**: Your product / niche / target audience (masked — don't write real company secrets or tactics).
- **Steps**:
  1. Use the "topic template" to produce ≥20 items, tag types, pick 3.
  2. For 1 chosen item, use the "headline + body template" to produce multiple versions.
  3. Use the "short-video script template" to produce 1 30–60s shot list.
  4. Do an originality check: data sourced, no absolute language.
- **Expected output**: One each of topic library + multi-version copy + short-video script.

### This Lesson's Prompt Template (Standard Structure)

**Topic template**

```
You are now playing the role of: a content operator who understands [industry] and is good at grabbing user pain points
My background is: we do [product/service], target users are [audience], this week need [number] pieces of content
The task I need to complete is: generate a batch of topics
The target user / reader is: [that audience's real anxiety]
Existing materials are as follows: [our selling points / recent hotspots, masked]
Please output: ≥20 topics, each with a headline direction + a type tag (substance / emotion / story / comparison / controversy)
Output format: numbered list, type in parentheses after
Constraints: don't copy specific accounts; no competitor secrets; positive and compliant angles
First ask me 3 key questions; if the information is sufficient, start directly.
Please output a version directly usable in work scenarios, with a checklist attached
```

**Headline + body template**

```
You are now playing the role of: a high-conversion, non-preachy content writer
My background is: the topic is "[chosen topic]", readers are [audience]
The task I need to complete is: write 1 body + give it 5 differently-styled headlines
The target user / reader is: [that audience]
Existing materials are as follows: [core info points, masked]
Please output: ① 5 headlines (one each: suspense / number / pain-point / identity / contrast); ② one body version, structure: hook + 3 points + call-to-action
Output format: headlines first, body after, Markdown
Constraints: data use [TBD] or real source; no "best / #1 / 100%" absolute language; don't fabricate cases
First ask me 3 key questions; if the information is sufficient, start directly.
Please output a version directly usable in work scenarios, with a checklist attached
```

**Short-video script template (Prompt Chaining step 2)**

```
You are now playing the role of: a short-video director
My background is: selected topic "[topic]", duration [30/60] seconds, platform [Douyin / Channels]
The task I need to complete is: write a shot-list script
The target user / reader is: [audience]
Existing materials are as follows: [key knowledge points]
Please output: a shot-list table with columns time / visual / narration / caption, ending with 1 cover-title line
Output format: table + one cover-title line
Constraints: natural non-preachy narration; no exaggerated-effect promises; accurate knowledge points
First ask me 3 key questions; if the information is sufficient, start directly.
Please output a version directly usable in work scenarios, with a checklist attached
```

## VI. Human Review Checklist

- [ ] Topics come from my real business, not copied from a specific account.
- [ ] Data in the copy have real sources or are marked "[TBD]" — no AI-fabricated percentages.
- [ ] No absolute/exaggerated language like "best / #1 / 100% effective."
- [ ] Core views are our original or authorized, not directly lifted.
- [ ] I read the short-video narration through; it doesn't sound like a robot reading.

## VII. Common Mistakes

1. **Asking for a "complete video" at once**: yields hollow output. Use prompt chaining step by step: topic → shot list → narration.
2. **Letting AI invent data**: "user growth 200%" was made up. You supply data or cite sources.
3. **Copying without originality check**: AI stitched online content; you publish it = plagiarism. Self-check before posting.
4. **Clickbait overkill**: writing exaggerated headlines for clicks — loses followers and breaks rules. Have hooks, keep the bottom line.
5. **Forgetting to mask**: writing unpublished campaign tactics into a Prompt sent to public AI.
