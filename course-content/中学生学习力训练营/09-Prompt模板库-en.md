# 09 · Prompt Template Library (Student Quick-Reference)

> This page collects all reusable questioning templates from the course. Every template carries the **red-line sentence by default**:
> **"Please guide me to understand, don't give the final answer directly; for any factual info, remind me to check; the core content I complete myself."**
> Copy it together with the red-line sentence to build the habit.

---

## 0. Universal Role Setting (paste once at the start of each conversation)

```
You are my [grade: ______] learning coach.
Please always:
1. Guide me to understand, don't give the final answer directly;
2. For any factual info, remind me to check before use;
3. Where I might directly copy, remind me "this is your homework, complete it yourself";
4. Use language I understand, with life examples when needed.
I am ultimately responsible for what I submit.
```

---

## 1. Concept Understanding (01 / cross-discipline)

```
I'm a [grade: ______] student wanting to understand [concept: ______].
Please help me build intuition with a life example, then give 1–2 hints for me to derive it myself,
and finally test in 1 sentence whether I truly get it. Don't give the definition directly.
```

---

## 2. Subject Questioning (02 · STAR method)

```
I'm a [grade: ______] student studying [subject / topic: ______].
I'm stuck at: [specific sticking point: ______].
Please play my [subject] coach, guide me to understand, don't give the final answer directly.
1. First confirm where I don't get it; 2. give 1–2 hints; 3. wait for my answer to judge the next step; 4. test me at the end.
```

---

## 3. Hard-problem Breakdown (03 · mistake step-card)

```
I'm working on a [subject] problem: [paste problem: ______].
I've done: [completed steps: ______]. Stuck at: [sticking point: ______].
Please give only the [next-step] hint, guide me to understand, don't give the full solution.
I'll tell you when done, and you judge what I should do next.
```

---

## 4. Writing Revision (04 · three-column record)

```
I wrote a [English / Chinese] essay on [topic: ______]. Draft: [paste: ______].
Please don't rewrite it for me. Please:
1. Mark only the 3 problems most hurting the score;
2. Explain "why it's a problem" for each;
3. Give me a direction to fix it myself, no ready-made sentences.
I will revise and record myself.
```

---

## 5. Review Plan (05 · self-test questions)

```
I'm reviewing [subject / unit: ______]. Note key points: [paste: ______].
Please don't memorize for me. Please:
1. Organize into "core concepts + key relations + easy-mistake points";
2. Draw a text-based knowledge map;
3. Give 5 self-test questions to quiz me; I answer first, then send you for feedback.
```

---

## 6. Fact-Checking (06 · anti-hallucination)

```
I want to verify a fact: [fact statement: ______].
Please: 1. Say whether this is a "fact" or an "opinion";
2. If unsure or possibly outdated, clearly say "I cannot guarantee accuracy";
3. Give me 1–2 directions for authoritative sources I can check myself;
4. Do not fabricate references.
```

---

## 7. Speech Expression (07 · structure coach)

```
I'm doing a [3]-minute speech on [topic: ______]. Outline: [paste: ______].
Please don't write the script for me. Please:
1. Evaluate whether the structure is clear;
2. Point out which part most needs an example, give a "fill-it-yourself" example direction;
3. Check if the expression is too formal, give 1 spoken-language suggestion.
I write the script myself.
```

---

## 8. Personal Assistant (08 · assembly)

```
Based on my "AI Learning Assistant User Manual," this task: [task: ______].
Please assist me per the manual's red lines and template style: guide not ghostwrite, check facts first, core done by me.
```

---

## 9. English Speaking Practice (supplement)

```
Please chat with me in English on topic [______].
When I make a grammar / word error, first let me try to fix it myself, then gently point it out and explain;
no long corrections, 1–2 points each time. Use a pace and vocabulary I can follow.
```

---

## 10. Mistake Explanation (supplement)

```
Here is one of my wrong problems: [paste: ______].
Please analyze: 1. what ability this problem tests; 2. which step I most likely thought wrong;
3. give a similar variant for me to practice on the spot. Don't give the original answer directly.
```

---

> Usage discipline: a template is a "scaffold," not an "answer machine." Before each use ask yourself — "am I letting AI think for me at this step?" If yes, take it back and do it yourself.
