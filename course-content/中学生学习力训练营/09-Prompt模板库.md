# 09 · Prompt 模板库（中学生速查版）

> 本页汇总全课程可直接复用的提问模板。所有模板默认携带**红线句**：
> **「请引导我理解，不要直接给最终答案；凡事实类信息提醒我核查；核心内容由我自己完成。」**
> 复制时连同红线句一起用，养成习惯。

---

## 0. 通用角色设定（每次对话开头贴一次）

```
你是我的【年级______】学习教练。
请始终：
1. 引导我理解，不直接给最终答案；
2. 凡事实类信息，提醒我先核查再使用；
3. 凡我可能直接复制的地方，提醒我"这是你的作业，要自己完成"；
4. 用我能听懂的语言，必要时用生活例子。
我提交的内容，最终责任在我自己。
```

---

## 1. 概念理解（01 / 跨学科）

```
我是【年级______】学生，想理解【概念：______】。
请用我生活中的例子帮我建立直觉，再给 1–2 个提示让我自己推导，
最后用 1 句话考我是否真懂。不要直接给定义。
```

---

## 2. 学科提问（02 · STAR 法）

```
我是【年级______】学生，正在学【学科/知识点______】。
我现在卡在：【具体卡点______】。
请扮演我的【学科】教练，引导我理解，不要直接给最终答案。
1. 先确认我哪里没懂；2. 给 1–2 个提示；3. 等我回答再判断下一步；4. 最后考我。
```

---

## 3. 难题拆解（03 · 错题分步卡）

```
我在做一道【学科】题：【粘贴题目______】。
我已做到：【已完成步骤______】。卡在：【卡点______】。
请只给【下一步】提示，引导我理解，不要给完整解答。
我做完会告诉你，你再判断我下一步该做什么。
```

---

## 4. 写作修改（04 · 三栏记录）

```
我写了一篇【英语/中文】作文，主题【______】。原稿：【粘贴______】。
请不要替我重写。请：
1. 只标出 3 处最影响分数的问题；
2. 每条解释"为什么是问题"；
3. 给我一个自己改的方向，不给现成句子。
我要自己修改并记录。
```

---

## 5. 复习计划（05 · 自测出题）

```
我在复习【学科/单元：______】。笔记要点：【粘贴______】。
请不要替我背书。请：
1. 整理成"核心概念+关键关系+易错点"；
2. 画文字版知识地图；
3. 出 5 道自测题考我；我先答，再发你给反馈。
```

---

## 6. 事实核查（06 · 防幻觉）

```
我要核实一个事实：【事实陈述______】。
请：1. 说明这是"事实"还是"观点"；
2. 若不确定或可能过时，明确说"我无法保证准确"；
3. 给我 1–2 个可自己核查的权威来源方向；
4. 不要编造参考文献。
```

---

## 7. 演讲表达（07 · 结构教练）

```
我要做【3】分钟演讲，主题【______】。提纲：【粘贴______】。
请不要替我写稿。请：
1. 评价结构是否清晰；
2. 指出哪段最需例子，给一个"可自己补充"的例子方向；
3. 看表达是否太书面，给 1 个口语化建议。
稿子我自己写。
```

---

## 8. 个人助手（08 · 组装）

```
基于我的《AI 学习助手使用手册》，本次任务：【任务______】。
请按手册的红线与模板风格协助我：引导而非代写，事实先核查，核心我自己完成。
```

---

## 9. 英语口语陪练（补充）

```
请用英语和我闲聊，话题【______】。
当我语法/用词错了，先让我试着自己改，再温和指出并解释；
不要长篇纠正，每次 1–2 点即可。用我能跟上的语速和词汇。
```

---

## 10. 错题讲解（补充）

```
这是我的一道错题：【粘贴______】。
请帮我分析：1. 这道题考的是什么能力；2. 我最可能哪一步想错；
3. 给一个同类变式题让我当场练。不要直接给原题答案。
```

---

> 使用纪律：模板是「脚手架」不是「答案机」。每次用前自问——「这一步我是不是在让 AI 替我思考？」如果是，收回，自己来。
