# 02 · 如何问出好问题 → 学科提问模板

## 教学目标

1. 理解「提问质量决定回答质量」——模糊的问题只会得到无用的回答。
2. 掌握结构化提问的四要素：背景、目标、约束、角色。
3. 建立分学科（数学 / 英语 / 历史 / 物理等）的提问模板卡。
4. 学会在提问中嵌入「引导式」要求，避免 AI 直接给答案。

---

## 开场问题

> 小明问 AI："帮我写一篇关于环保的作文。"
> 小红问 AI："我是初二学生，要写一篇 600 字议论文，观点是'垃圾分类从小事做起'，请先给我 3 个论点和对应的生活例子，不要写全文，我想自己写。"
>
> 谁拿到的东西更有用？为什么？——**好问题，是学好的第一步。**

---

## 核心概念

### 1. 为什么提问这么重要
大语言模型是「顺着你的话走」的。你说得越清楚，它越能帮上忙；你说得含糊，它只能猜，结果往往用不上。

### 2. 好问题的四要素（STAR 法）
- **Situation 背景**：我是谁、在哪个年级、在学什么。
- **Task 任务**：我想要什么（思路 / 反馈 / 解释 / 练习）。
- **Action 约束**：长度、风格、不要直接给答案等。
- **Role 角色**：让 AI 扮演「教练 / 老师 / 陪练」。

### 3. 从「要答案」转向「要理解」
在问题里加上：**"请引导我理解，不要直接给最终答案，我想自己完成。"**

### 4. 迭代式提问
第一轮先要框架，第二轮要提示，第三轮要反馈——好问题是一步步「问出来」的，不是一次到位。

---

## 学习场景案例

### 数学错题
- 模糊："这道函数题怎么做？"
- 好问题："我是高一学生，这道二次函数题我卡在'如何配方'这一步。请只提示配方的思路，引导我自己配出来，不要给完整解答。"

### 英语作文
- 模糊："帮我改这篇作文。"
- 好问题："我是初三学生，下面是我写的 120 词英语短文，请指出 3 处最影响分数的语法/用词问题，并解释为什么错，让我自己改，不要重写。"

### 历史资料
- 模糊："太平天国讲一下。"
- 好问题："我在预习太平天国，教材说它是'反封建反侵略'。请帮我列出 3 个能支撑这个评价的具体史实，并标出哪条争议最大、为什么有争议。"

### 物理概念
- 模糊："牛顿第二定律是什么？"
- 好问题："我用'推购物车'的例子理解 F=ma 总卡在'质量越大越难加速'。请用这个例子引导我，不要直接背公式。"

---

## 正确 vs 错误使用对比

| | ❌ 错误提问 | ✅ 正确提问 |
| --- | --- | --- |
| 信息量 | 没背景、没目标 | 有年级、有具体卡点 |
| 期望 | 直接给成品 | 要思路/反馈/引导 |
| 结果可用性 | 空泛，用不上 | 精准，能接着做 |
| 学习发生 | 没发生 | 发生在你身上 |

## 动手任务

1. 从你最近一门课的作业里，挑一个你没懂的点。
2. 先写一个「模糊问题」，再改写成「STAR 好问题」。
3. 把改写后的问题输入 AI，验证它给你的东西是否真的能用；若不行，继续迭代一轮。
4. 把最终版问题抄进你的「学科提问模板卡」。

---

## Prompt 模板（中学生版）

```
我是【年级______】学生，正在学【学科/知识点______】。
我现在卡在：【具体卡点______】。
请扮演我的【学科】教练，引导我理解，不要直接给最终答案。
我希望你：
1. 先确认我哪里没懂；
2. 给 1–2 个提示让我自己往前走；
3. 等我回答后，再判断要不要给更多线索；
4. 最后用 1 个问题考我是否真懂。
```

> 红线：任何学科模板都带「引导我理解，不要直接给最终答案」。

## 人工检查清单（学生自查）

- [ ] 我的问题里有「我是谁 / 在学什么 / 卡在哪」三要素。
- [ ] 我明确要求 AI 不要直接给答案。
- [ ] 我用过一次，并确认回答对我有用。
- [ ] 我把好问题抄进了模板卡，方便下次复用。

---

## 常见错误

1. **问题太短太泛**："帮我学数学"——AI 无从下手。
2. **一次要太多**：又要解释又要写作文又要出题，结果都浅。
3. **忘了说「不要给答案」**：AI 顺手给了成品，你又抄了。
4. **不迭代**：第一次不好用就放弃，其实改个问题就行。

## 课后作业

1. 制作你的「学科提问模板卡」：数学、英语、历史/语文、物理/生物各写 1 条 STAR 好问题（共 4 条）。
2. 选其中 1 条真实用 AI 试一次，记录 AI 的引导和你的收获。
3. 反思：过去你最常犯哪种「坏问题」？以后怎么改？

## 本节小结与进阶

好问题 = 清楚的背景 + 明确的目标 + 合理的约束 + 合适的角色。多数「AI 答非所问」，根子在「我问得不清楚」。把提问当成一种可练习的技能：先写草稿，再改精准，最后看 AI 给的东西能不能接住你的下一步。

### 提问的五个「动词法」
写问题时，多用这五个动词开头，问题立刻变具体：
- **解释**：请解释……（要理解）
- **提示**：请提示我……（要线索）
- **比较**：请比较 A 和 B……（要辨析）
- **举例**：请举一个生活中的例子……（要直觉）
- **核查**：请帮我核查……（要验证）
避免只用「写/做/给」这类一锤子买卖的动词。

### 给家长/老师的一句话
鼓励孩子把「好问题」存进文档，形成自己的提问库。班里可以每周评选「本周最佳提问」，让「会问」和「会答」一样被看见、被奖励。

## 评分标准（满分 10 分）

| 项目 | 分值 | 说明 |
| --- | --- | --- |
| 模板卡完整 | 3 | 4 学科各 1 条，要素齐全 |
| STAR 运用 | 3 | 背景/任务/约束/角色清晰 |
| 引导式要求 | 2 | 含「不要直接给答案」 |
| 实践与反思 | 2 | 有真实试用 + 自我改进 |
