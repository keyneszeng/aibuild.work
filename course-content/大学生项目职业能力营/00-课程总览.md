# AI 项目与职业能力营 · 课程总览

> 面向大学生 / 研究生 / 应届求职者的一门「项目驱动 + 职业导向」AI 实战训练营。
> 目标不是学会更多 Prompt，而是用 AI 完成一次完整的 **调研 → 设计 → 执行 → 展示** 闭环，产出能写进简历、带进面试、挂上个人主页的作品集。

---

## 一、这门课解决什么痛点

很多同学对 AI 并不陌生：用 ChatGPT 写周报、用 Copilot 补全代码、刷过几个教程。但当被问到「你用 AI 做过什么项目」「你的作品集在哪」时，往往答不上来。问题不在工具，而在 **缺少一条把能力沉淀为作品的生产线**。

本营把 AI 能力拆成 8 个可交付环节，每个环节都要求你产出一个真实文档或原型：

- 调研能力（行业调研报告）
- 阅读能力（论文 / 资料阅读笔记）
- 分析能力（数据洞察小报告）
- 求职能力（简历 + 模拟面试记录）
- 设计能力（项目计划书）
- 原型能力（无代码 / 低代码 Demo）
- 包装能力（作品集 / 展示页）

这 8 个环节最终汇聚成一份 **AI 原生作品集**，它比「我会用 AI」这句话有力一百倍。

## 二、目标人群

| 人群 | 典型诉求 | 本营能给到的 |
| --- | --- | --- |
| 本科生 | 想做科研 / 竞赛 / 实习，但不知从哪下手 | 论文阅读、行业调研、项目雏形 |
| 研究生 | 有研究方向，缺工程化与表达 | 数据分析、原型、作品集包装 |
| 应届求职者 | 简历单薄、面试没故事 | 简历优化、模拟面试、可展示项目 |
| 转行 / 跨专业者 | 非技术背景，想用 AI 提效 | 低代码路径、非工程视角的应用认知 |

本营不要求你有编程基础。涉及代码的部分都提供「无代码替代方案」（如 Coze、Dify、飞书多维表格、Streamlit 模板），你可以只做文档与产品侧交付物。

## 四、内容来源与方法论（已抓取并本地化重组的参考仓库）

本课程并非凭空编写，而是对以下 7 个国际权威开源仓库进行 **抓取 + 中文本地化重组 + 学生视角重构** 而来。每个仓库贡献了不同的底层方法论：

1. **microsoft/AI-For-Beginners** —— AI 基础框架：符号 AI、神经网络、计算机视觉、NLP、Transformer、LLM 与提示编程、AI 伦理。对应本营「基础认知」与「负责任使用」。
2. **microsoft/generative-ai-for-beginners** —— 21 课生成式 AI 应用：提示工程、RAG、向量库、低代码应用、AI Agent、函数调用、微调。对应本营「应用原型」「项目设计」。
3. **openai/openai-cookbook** —— API 实战示例库：如何把大模型能力落到具体任务（分类、摘要、抽取、生成数据、评估）。对应本营「把 API 思路转成非工程可理解的应用认知」。
4. **mlabonne/llm-course** —— 技术进阶框架：LLM Fundamentals / LLM Scientist / LLM Engineer 三段式，覆盖微调、量化、部署、评测。对应本营「进阶路径」与「技术纵深地图」。
5. **DataTalksClub/llm-zoomcamp** —— RAG / 知识库实战：Agentic RAG、向量检索、评估、监控、端到端 Capstone。对应本营「知识库助手」「毕业项目」结构。
6. **datawhalechina/llm-universe** —— 中文社区「动手学大模型应用开发」：调用 API、搭知识库、构建 RAG、Streamlit 部署、验证迭代。对应本营「低代码 Demo」「本地化表达」。
7. **dair-ai/Prompt-Engineering-Guide** —— 提示工程方法论：Zero-Shot / Few-Shot / CoT / Prompt Chaining / ToT / RAG / ReAct 等技术谱系。对应本营「Prompt 模板库」「大学生版三问结构」。

> 重组原则：原仓库偏「技术实现 / 英文读者 / 工程师」，本营偏「学生视角 / 中文 / 项目与职业产出」。只保留与「调研—设计—执行—展示」主线相关的内容，删除纯算法推导，补充求职、作品集、可展示交付物等本地化模块。

## 五、每节课的统一结构（你会在 01–08 每课看到）

- **教学目标**：这节课结束你能做到什么
- **开场问题**：用一个真实困境引入
- **核心概念**：必须掌握的知识点（口语化）
- **真实场景案例**：来自学生 / 求职者的真实情境
- **动手任务**：含 工具清单 / 任务说明 / 示例 Prompt / 评价标准
- **Prompt 模板（大学生版）**：额外要求给出【资料来源】【分析过程】【可复用结构】
- **人工检查清单**：AI 生成后你人工必须核对的项
- **常见错误**：新人最容易踩的坑
- **课后作业**：必须是一个可展示作品
- **评分标准**：可量化打分，便于自评与他评

## 六、学习成果与考核

**过程分（60%）**：01–08 每课交付物，按评分标准自评 + 同伴互评。
**毕业分（40%）**：09 课三选一毕业项目，或自选等价项目，需满足：
- 有可演示的 Demo 或完整文档
- 有作品集展示页
- 能一句话讲清「解决了什么问题、怎么解决的、结果如何」

**红线（不可逾越）**：
1. 至少完成 1 个可展示作品（不满足则不予结业）。
2. 内容不能只停留在 Prompt，必须有完整的项目过程（调研 / 设计 / 执行 / 展示）。
3. 作品必须能进简历、面试、个人主页，语言项目化、职业化，杜绝「AI 帮我写」的空泛表述。

## 八、给学习者的三条建议

1. **先完成，再完美**：每一课先产出一个「能看」的版本，再迭代。作品集是迭代出来的，不是一次写成的。
2. **让你的 AI 留下痕迹**：保留 Prompt、原始资料、修改过程，这本身就是面试时能讲的故事。
3. **公开学习（Learning in Public）**：把作品发到 GitHub / 博客 / 朋友圈，参考 llm-zoomcamp 的「Learning in Public」理念，曝光会带来反馈与机会。
