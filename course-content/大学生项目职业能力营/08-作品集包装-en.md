# Lesson 08 · Portfolio Packaging

## 1. Learning Goals

- **Knowledge**: Understand that a "portfolio" is stronger evidence than a résumé — it lets people see "how you did it, what you made"; master the showcase structure "project background—problem—solution—process—result—reflection"; know the value of a personal homepage/showcase page.
- **Capability**: Package the outputs of the previous 7 lessons (research report / paper notes / data report / résumé / plan / Demo) into a unified-style portfolio; write a project showcase page.
- **Artifact**: An "AI Project Portfolio" (with ≥2 complete project showcases + personal intro).

> This lesson integrates the previous 7 lessons' outputs, referencing LLM Universe's "turn learning outcomes into projects" and product-on-purpose/pm-skills' "artifact as evidence" philosophy.

## 2. Warm-up Question

> Interviewer asks "what projects have you done", you flip through chat history to find now?
> A pile of scattered documents, nobody knows what you can actually do?
> Want to host a personal homepage, but don't know what to put, how to write?

A portfolio is displaying your capability. It turns "I know how to use AI" into "look, this is what I built".

## 3. Core Concepts

### 1. Six-section showcase structure
Background (why built) → Problem (what solved) → Solution (how built) → Process (key steps/screenshots) → Result (data/feedback) → Reflection (pitfalls & improvement).

### 2. Quality > Quantity
2 thoroughly-written projects beat 10 half-done ones. Each must have "result" and "reflection".

### 3. Personal homepage
Use Feishu/Notion/GitHub Pages to build a page with intro + project links, send the link directly in interviews.

### 4. Red line: present truthfully
Demo screenshots and data must be real; write "led" vs "participated" honestly.

## 4. Real-scenario Case Demonstration

### Case: portfolio project card
- Title: AI study-material organizer
- Background: scattered final-exam materials
- Solution: Coze knowledge-base bot (see Lesson 07)
- Process: 3 screenshots (build / knowledge base / test chat)
- Result: classmates tried "find materials twice as fast"
- Reflection: knowledge base needs more structure, else answers drift

## 5. Hands-on Task

- **Background**: Aggregate all outputs of the previous 7 lessons.
- **Input**: your reports / notes / Demo / plan.
- **Steps**:
  1. Pick ≥2 projects, write as showcase pages in the six-section structure.
  2. Write a personal intro paragraph (capability map).
  3. Assemble into a portfolio document or homepage.
- **Expected output**: "AI Project Portfolio".

## 6. Prompt Template

```
You are now playing: portfolio mentor
I have the following project outputs: [list]
Please help me:
1. In the six sections [background/problem/solution/process/result/reflection], write showcase copy for 2 of them;
2. Write a 100-char personal intro highlighting my AI capability map;
3. Give portfolio layout suggestions (Notion/Feishu both fine).
Constraint: all data/screenshots must be real, don't exaggerate my role.
```

## 7. Human Review Checklist

- [ ] Each project has result and reflection
- [ ] Data/screenshots real
- [ ] Role description honest (led/participated)
- [ ] Homepage/document accessible to others

## 8. Common Mistakes

1. Only screenshots no explanation.
2. Project has no "result", looks unfinished.
3. Exaggerate personal contribution.
4. Portfolio has no unified style, looks patched together.

## 9. Homework

Submit an "AI Project Portfolio" (≥2 projects in six-section showcase + personal intro).

## 10. Grading Rubric

- Completion: portfolio complete (40%)
- Quality: complete structure, has result & reflection (35%)
- Integrity: real, not exaggerated (25%)
