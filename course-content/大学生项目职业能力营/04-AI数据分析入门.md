# 第 04 课 · AI 数据分析入门 → 一个数据洞察小报告

## 教学目标
学完本课，你将能够：
1. 用自然语言驱动一次完整的数据分析（无需写代码，或只写极少量）；
2. 区分「描述数据」和「洞察数据」——后者才是报告价值所在；
3. 产出第四件作品：**一份《数据洞察小报告》**（含问题、数据、发现、建议），可用于课程大作业、实习产出、商业分析岗面试。

---

## 开场问题
> 社团拉了一份 2000 人的活动报名表，会长说「你分析一下」。你对着 Excel 发呆：人数、均值、图表都做了，然后呢？「然后」才是洞察。
> 数据本身不说话，AI 帮你把「数字」翻译成「结论」和「行动」。

---

## 核心概念

**1. 描述 ≠ 洞察**
- 描述：去年报名 2000 人，女生占 60%。
- 洞察：女生占比偏高且来自 3 个院系，说明活动主题对理工科男生吸引力不足，下次应调整宣传渠道。
洞察 = 描述 + 对比/归因 + 行动建议。

**2. 分析工作流（无代码版）**
参考 openai/openai-cookbook 的「分类 / 摘要 / 抽取」思路，把分析拆成：明确问题 → 清洗数据 → 描述统计 → 找异常/分组差异 → 形成假设 → 给建议。AI 在每一步都能辅助，但「假设」必须你来提。

**3. 数据清洗是 80% 的活**
缺失值、重复行、格式不一致——这些脏活 AI 能帮你写公式/脚本处理，但你要先说清规则。参考 llm-zoomcamp 的 Data Ingestion 模块理念：先把数据弄干净，模型才有用。

**4. 用 Python/Notebook 的进阶路径（可选）**
若你有基础，可用 Python（pandas）+ 对话模型写脚本；无基础用飞书多维表格 / Excel + AI 公式助手同样能完成。本课两条路径都给。

---

## 真实场景案例
> 佳怡，市营大四，在电商实习。她拿到一份 3 万行的订单表，用 AI 写出 Python 脚本做 RFM 分层（最近购买/频率/金额），发现「高价值低活跃」客户占比 18% 却贡献 45% 营收，建议做召回活动。这份分析被主管采用，成为她简历上「用数据驱动决策」的实锤。

## 动手任务

**工具清单**：Excel / 飞书多维表格、Python（可选，pandas）、对话模型、公开数据集（Kaggle / 国家数据 / 学校公开数据）。

**任务说明**：
1. 找一份真实的表格数据（课程成绩、问卷、销售、活动报名皆可），≥200 行。
2. 用 AI 帮你列 3 个分析假设（如「不同渠道转化差异显著」）。
3. 清洗：让 AI 写公式/脚本处理缺失与重复，你核对结果。
4. 描述 + 洞察：对每个假设给出数据证据，并写「这对决策意味着什么」。
5. 输出报告：问题 → 数据与方法 → 3 个发现 → 行动建议 → 局限。

**示例 Prompt（大学生版 · 无代码分析）**：
```
我有一份【数据描述，如 2000 行活动报名表，字段有院系/年级/渠道/是否到场】。
请帮我：
1）提出 3 个有价值的分析假设（要能指导后续行动，而非纯描述）；
2）列出我需要在表格里做的清洗步骤（用自然语言，我会用 Excel/多维表格操作）；
3）对每个假设，给出我应该看的指标和对比维度；
4）提醒我这份数据可能有哪些偏差（如样本不均）会影响结论。
【资料来源】请只基于我描述的字段和常见问题类型，不要编造我数据里没有的列。
【分析过程】请说明你如何从「字段」推导出「假设」。
【可复用结构】请给我一个「假设-指标-结论-建议」四段分析模板。
```

**评价标准**：
- 数据已清洗并说明规则（20%）
- 有 ≥3 个分析假设而非纯描述（30%）
- 每个发现都有数据证据 + 行动建议（30%）
- 标注数据局限/偏差（10%）
- 报告可展示（10%）

---

## Prompt 模板（大学生版 · 三问结构）

> 【资料来源】要求 AI 只基于你真实拥有的字段，防止它假设不存在的列。
> 【分析过程】要求 AI 显式从字段推出假设，便于你判断假设是否合理。
> 【可复用结构】「假设-指标-结论-建议」四段式，适用于所有业务分析。

## 人工检查清单
- [ ] 我核对了 AI 生成的公式/脚本确实跑对了
- [ ] 结论都有数据支撑，没有「感觉应该是」
- [ ] 我区分了相关与因果，没有乱下结论
- [ ] 报告里有「这对决策意味着什么」
- [ ] 我标注了数据的样本偏差与局限
- [ ] 保留了原始数据与处理记录

---

## 常见错误
1. **只做描述统计**：堆图表但无结论，读者不知道「所以呢」。
2. **AI 编造字段**：它假设了「消费金额」列，而你数据里根本没有。
3. **相关当因果**：A 和 B 同时出现就说是因果，被追问就露馅。
4. **忽略样本偏差**：2000 人全来自一个院系，结论不能外推。
