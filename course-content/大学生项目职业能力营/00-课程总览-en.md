# AI Project & Career Capability Camp · Course Overview

> A "project-driven + career-oriented" hands-on AI bootcamp for university students / graduate students / new graduates.
> The goal is not to learn more Prompts, but to use AI to complete a full **research → design → execution → showcase** loop, producing a portfolio you can put on your résumé, bring to interviews, and host on a personal homepage.

---

## 1. What Pain Points This Course Solves

Many students are no strangers to AI: they have used ChatGPT to write weekly reports, Copilot to autocomplete code, and watched a few tutorials. But when asked "What AI projects have you built?" or "Where is your portfolio?", they often have no answer. The problem is not the tools — it is the **lack of a production line that turns capability into tangible artifacts**.

This camp breaks AI capability into 8 deliverable stages, each requiring you to produce a real document or prototype:

- Research capability (industry research report)
- Reading capability (paper / material reading notes)
- Analysis capability (data insight mini-report)
- Job-seeking capability (résumé + mock interview notes)
- Design capability (project plan)
- Prototyping capability (no-code / low-code Demo)
- Packaging capability (portfolio / showcase page)

These 8 stages converge into an **AI-native portfolio** — far more powerful than the phrase "I know how to use AI".

## 4. Content Sources & Methodology (fetched and localized repositories)

This course was not written from scratch. It was produced by **fetching + Chinese-localization restructuring + student-perspective reconstruction** of the following 7 internationally authoritative open-source repositories. Each contributes a different underlying methodology:

1. **microsoft/AI-For-Beginners** — AI fundamentals: symbolic AI, neural networks, computer vision, NLP, Transformer, LLM & prompt programming, AI ethics. Maps to this camp's "foundational literacy" and "responsible use".
2. **microsoft/generative-ai-for-beginners** — 21 lessons on generative AI applications: prompt engineering, RAG, vector stores, low-code apps, AI Agent, function calling, fine-tuning. Maps to this camp's "application prototype" and "project design".
3. **openai/openai-cookbook** — API practical examples: how to apply LLM capability to specific tasks (classification, summarization, extraction, data generation, evaluation). Maps to this camp's "translating API thinking into non-engineering-comprehensible application awareness".
4. **mlabonne/llm-course** — Technical progression framework: LLM Fundamentals / LLM Scientist / LLM Engineer three-stage, covering fine-tuning, quantization, deployment, evaluation. Maps to this camp's "progression path" and "technical depth map".
5. **DataTalksClub/llm-zoomcamp** — RAG / knowledge base practice: Agentic RAG, vector retrieval, evaluation, monitoring, end-to-end Capstone. Maps to this camp's "knowledge-base assistant" and "capstone project" structure.
6. **datawhalechina/llm-universe** — Chinese-community "Hands-on LLM Application Development": calling APIs, building knowledge bases, constructing RAG, Streamlit deployment, validation iteration. Maps to this camp's "low-code Demo" and "localized expression".
7. **dair-ai/Prompt-Engineering-Guide** — Prompt engineering methodology: Zero-Shot / Few-Shot / CoT / Prompt Chaining / ToT / RAG / ReAct technique spectrum. Maps to this camp's "Prompt template library" and "student-version three-question structure".

> Restructuring principle: the original repos lean toward "technical implementation / English readers / engineers", while this camp leans toward "student perspective / Chinese / project & career output". We keep only content relevant to the "research—design—execution—showcase" main line, delete pure algorithmic derivations, and add localized modules such as job-seeking, portfolio, and demonstrable deliverables.

## 5. Unified Structure of Each Lesson (seen in Lessons 01–08)

- **Learning Goals**: what you can do after this lesson
- **Warm-up Question**: introduced with a real dilemma
- **Core Concepts**: knowledge points you must master (in plain language)
- **Real-scenario Case**: real situations from students / job seekers
- **Hands-on Task**: includes tool list / task description / sample Prompt / evaluation criteria
- **Prompt Template (student version)**: additionally requires 【Sources】【Analysis Process】【Reusable Structure】
- **Human Review Checklist**: items you must manually verify after AI generation
- **Common Mistakes**: the pitfalls beginners most easily fall into
- **Homework**: must be a demonstrable artifact
- **Grading Rubric**: quantifiable scoring for self- and peer-assessment

---

## 6. Learning Outcomes & Assessment

**Process score (60%)**: deliverables of Lessons 01–08, self-assessed + peer-assessed per the grading rubric.
**Capstone score (40%)**: choose 1 of 3 capstone projects in Lesson 09, or an equivalent self-chosen project, satisfying:
- Has a demonstrable Demo or complete documentation
- Has a portfolio showcase page
- Can state in one sentence "what problem it solved, how it was solved, and what the result was"

**Red Lines (cannot be crossed)**:
1. Complete at least 1 demonstrable artifact (failure to do so means no graduation).
2. Content must go beyond Prompts — it must include a complete project process (research / design / execution / showcase).
3. The artifact must be résumé-, interview-, and homepage-ready: phrased project-wise and professionally, eliminating empty statements like "AI helped me write it".

## 8. Three Suggestions for Learners

1. **Finish first, perfect later**: for each lesson, produce a "viewable" version first, then iterate. A portfolio is iterated, not written once.
2. **Let your AI leave traces**: keep Prompts, raw materials, and revision history — this is itself a story you can tell in interviews.
3. **Learn in Public**: publish your work to GitHub / blog / social feed, following llm-zoomcamp's "Learning in Public" philosophy — exposure brings feedback and opportunities.
