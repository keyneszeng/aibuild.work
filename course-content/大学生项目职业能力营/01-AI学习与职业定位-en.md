# Lesson 01 · AI Learning & Career Positioning → Personal AI Capability Map

## Learning Goals
After this lesson, you will be able to:
1. Use one diagram to clearly state "what I can do now, what I lack, what to learn next";
2. Break the vague "I want to learn AI" into executable skill nodes;
3. Produce your first artifact: **"Personal AI Capability Map"** (one table + a 200-character self-positioning paragraph). It serves as your navigation through the whole camp and lets you explain your AI literacy in the first 30 seconds of an interview.

---

## Warm-up Question
> Interviewer: "How do you usually use AI?" You: "Just use ChatGPT to write stuff." — And then?
> Most students have used AI, but **use it and forget, use it without retaining anything**. This lesson helps you gather scattered experiences into a demonstrable capability map.

---

## Core Concepts

**1. AI literacy is not "knowing how to use tools" but "knowing how to use AI to solve problems"**
Following microsoft/AI-For-Beginners' definition, AI capability includes at least: understanding what AI can do (cognitive layer), being able to use AI for specific tasks (application layer), and knowing AI's boundaries and risks (ethics layer). This camp focuses on the application and ethics layers, with only enough cognitive-layer groundwork.

**2. Capability map = dimension × level × evidence**
- Dimension: research, reading, analysis, writing, prototyping, job-seeking, collaboration…
- Level: 0 never touched / 1 tried it / 2 can do independently / 3 can do for others to see / 4 can teach others
- Evidence: each level must be backed by an artifact or experience, avoiding "self-rated 4 but nothing to show".

**3. Career positioning = problems you want to solve × your professional background**
AI is not a major, it is a "magnifier". Biochemistry + AI = literature-retrieval assistant; business + AI = industry-research assistant; design + AI = prototype generation. The key is to connect AI to your major, not to "learn AI itself" detached from your field.

**4. Progression path reference (mlabonne/llm-course three-stage)**
- LLM Fundamentals (math / Python / neural-network basics, optional)
- LLM Scientist (push the model to its best: fine-tuning, quantization, evaluation)
- LLM Engineer (turn the model into a deployed application)
This camp mainly lands on the Engineer application side; return to Scientist as needed for technical depth.

## Hands-on Task

**Tool list**: ChatGPT / Kimi / DeepSeek (any conversational model), Feishu Multi-dimensional Tables or Excel, Markdown editor (Typora / Obsidian).

**Task description**:
1. List 6–8 AI capability dimensions (suggested: material research, paper reading, data analysis, content writing, code/prototyping, job-seeking expression, project management, AI ethics & risk control).
2. Score each dimension 0–4 and write one "evidence" sentence (e.g., "Research 3: used AI to complete course-paper material collection").
3. Mark 2 "most want to improve" dimensions, mapping to Lessons 02–08 of this camp.
4. Write a 200-character self-positioning: who am I, my major, what I want to solve with AI, what I want this map to become by camp end.

**Sample Prompt (student version · generate capability map draft)**:
```
You are my AI learning coach. I am a [major/year] student who has used AI to [give 2 real examples].
Please help me:
1) List 8 AI capability dimensions suitable for student self-assessment;
2) For each dimension give 0–4 self-rating anchors (what counts as 1 / 2 / 3 points);
3) Based on my info, first give a preliminary scoring suggestion.
Requirements: in Chinese, structured, no empty talk; each dimension tied to "artifacts a student can produce".
```

**Evaluation criteria**:
- Dimension coverage ≥6, including ethics/risk control (30%)
- Each dimension has level + evidence, no empty rating (30%)
- Self-positioning within 200 chars, with professional anchor (20%)
- Clear connection to subsequent camp lessons (20%)

## Prompt Template (student version · three-question structure)

> 【Sources】This lesson is based on microsoft/AI-For-Beginners' three-layer AI-literacy model and mlabonne/llm-course's three-stage progression.
> 【Analysis Process】First define "capability dimensions" rather than "tool names" to avoid turning the map into a software list; then use "evidence" to constrain self-rating inflation; finally use "professional anchor" to reconnect AI to personal background.
> 【Reusable Structure】Dimension × Level (0–4) × Evidence three-column table, applicable to any skill self-assessment scenario (e.g., programming ability, English ability).

## Common Mistakes
1. **Writing the capability map as a tool list**: "I know ChatGPT, Midjourney" — that is not capability, it is software names.
2. **Inflated self-rating**: rating everything 4 but showing no artifact. Exposed the moment you are asked.
3. **Detached from major**: only talking about "learning AI", not "using AI to solve problems in my field".
4. **One-shot, no iteration**: the map is alive; return to update it once at camp end.
