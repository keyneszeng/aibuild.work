# 第 11 课  Prompt 模板库（儿童版）

> 给家长和孩子的"会说话的小卡片"。每条都用「我想让 AI 帮我……」开头，简单、具体、孩子能自己念。
> 使用前先读第 9 课家长指南、第 10 课安全手册。

## 一、通用开口（每条都先说这句）

```
我想让 AI 帮我[做一件具体的事]。
我是[几岁]的小朋友，请说[简单/有趣]的话。
```

## 二、按课程分类的模板

### 第 1 课 · AI 是什么
```
我想让 AI 帮我画一画"我心中的 AI 助手"长什么样。
它有什么超能力？请描述给我，我用笔画下来。
```

### 第 2 课 · 如何提问
```
我想让 AI 帮我：我要问关于[恐龙/星星/小狗]的问题。
请先教我 3 种问法，让我比比哪种问得清楚。
```

### 第 3 课 · 一起讲故事
```
我想让 AI 帮我写一个童话：主角是[一只会做饭的小狐狸]，
它要去[拯救被乌云盖住的天空]。请和我一起，一段一段写。
```

### 第 4 课 · 一起画角色
```
我想让 AI 帮我设计一个角色：它是[住在云上的小工程师]，
喜欢[收集彩虹]。请写出它的样子和一段画图用的提示词，我拿去画。
```

### 第 5 课 · 认识世界
```
我想让 AI 帮我解释：为什么[晚上星星会出来]？
请用[8岁小朋友]听得懂的话说，再出一道小问题考我。
```

### 第 6 课 · AI 也会错
```
我想让 AI 帮我玩"真假游戏"：你故意说 3 句关于[动物]的话，
其中 1 句是假的，让我猜哪句是编的，并告诉我答案。
```

### 第 7 课 · 我的未来发明
```
我想让 AI 帮我设计"未来的[会自己收拾书包的桌子]"：
它怎么工作？长什么样？请写出样子，我画设计稿。
```

### 第 8 课 · 创作展示
```
我想让 AI 帮我：把我的[5个故事+5张画]拼成一个"AI 绘本"。
请给绘本起个名字，写一段开场白。
```

## 三、给家长的"陪问"提示

- 让孩子**自己念**想做的事，锻炼表达。
- AI 答完，问孩子："你觉得它说得对吗？哪里好玩？"
- 鼓励孩子**改 AI 的话**："让 AI 换一种说法试试。"

## 四、安全提醒（每次都用）

- 不填真名、学校、电话。
- AI 说"真的假的不确定"时，查书或问大人。
- 不抄 AI 答案当作业。

> 模板是"脚手架"，孩子的想法才是主角。AI 帮他把想法变出来，主角永远是孩子。
