# 《AI 产品经理进阶营》课程总览

> 面向有产品经验的产品经理与创业者，目标不是"会用 AI 工具"，而是"会设计 AI 产品"。

## 一、课程定位

本课程是一门**产品设计与交付导向**的进阶训练，而不是"AI 工具使用入门"。市面上大量内容停留在"用 ChatGPT 写周报""用 Cursor 写代码"，但真正稀缺的能力是：把 AI 的不确定性、概率性、涌现能力，转化为可被工程、算法、数据、运营协作落地的产品方案。

我们借用几套成熟的开源资料作为底层知识底座：
- **Product-Manager-Skills**（deanpeters）：77 个经过实战检验的 PM 框架与 Triple Diamond 方法论，提供 PRD、用户故事、机会树、JTBD、优先级等结构化交付物范式。
- **Awesome AI Product Management**（aza-ali）：AI PM 的工具、心智模型、书单（Inspired / Empowered / The Coming Wave / AI Product Playbook / Art of AI Product Development）与行业报告（Sequoia《Services: The New Software》、Stanford AI Index）。
- **ai-agent-camp**（minicoohei）：面向非工程角色的 AI Agent 通识——LLM 原理、Token、Agent、Context Engineering、MCP、多模态、RAG、幻觉防控、安全。
- **easy-vibe**（datawhalechina）：从想法到原型的产品验证路径（Double Diamond、Jobs to Be Done、The Mom Test）。
- **Prompt-Engineering-Guide**（dair-ai）：Zero-shot / Few-shot / CoT / ReAct / RAG / Function Calling 等提示工程技术谱系。

本课程将上述知识**重组为产品经理可执行的产物**：每节课都要求产出产品文档、流程图或指标表，而非停留在概念。

## 二、目标用户

| 用户画像 | 现状 | 痛点 | 本课程给他的 |
|---|---|---|---|
| 有 2-5 年经验的产品经理 | 懂需求、懂 PRD，但 AI 项目"看不懂、接不住" | 分不清 AI 功能该用 RAG 还是 Agent；无法评估模型效果；和算法对话费劲 | AI 产品能力地图 + 可落地的 PRD/RAG/Agent 模板 |
| 创业者 / 业务负责人 | 想用 AI 改造业务，但被技术名词劝退 | 不知道 AI 能解决什么、成本多高、风险在哪 | 机会分析方法 + 商业化方案模板 |
| 转型中的传统软件 PM | 做过确定性系统，第一次做概率系统 | 难以接受"结果不确定"，不会做容错与人审 | 评估体系 + 风险清单 + 人工介入设计 |

## 三、核心痛点（我们要解决什么）

1. **只会用工具，不会设计产品**：把"让 AI 写文案"当成产品方案，缺少用户场景、指标、边界与风控。
2. **把 AI 当传统软件**：忽略不确定性、幻觉、延迟、成本，上线即翻车。
3. **交付物缺位**：没有 AI 版的 PRD、Agent 流程图、评估测试集，工程/算法无法接手。
4. **评估盲区**：只有"感觉还行"，没有可量化的命中率、人工介入率、幻觉率。
5. **协作失语**：不懂 RAG、向量库、Agent、上下文工程，与算法/工程会议效率低。

## 四、学习路径（00 → 15）

```
00 总览
 ├─ 基础认知
 │   01 AI 产品基础（能力地图）
 │   02 与传统软件差异（机会分析）
 │   03 Prompt 与交互设计（交互方案）
 ├─ 核心能力模块
 │   04 RAG / 知识库（PRD）
 │   05 Agent 工作流（流程图）
 │   06 多模态（功能方案）
 ├─ 工程化交付
 │   07 评估体系（指标 + 测试集）
 │   08 成本 / 延迟 / 体验（约束表）
 │   09 风险安全合规（风险清单）
 │   10 商业化（完整方案）
 └─ 可直接复用的产物
     11 PRD 模板
     12 Agent 工作流模板
     13 评估指标表
     14 五个产品案例
     15 Prompt 模板库
```

**节奏建议**：前 6 节每节约 2 小时（阅读 + 写一份产物）；07-10 为工程化与商业化，每节产出一张表或一个方案；11-15 是贯穿全课的"工具箱"，随时回查。

## 五、每节交付物（红线）

- **不只讲概念**：每节必须产出**产品文档 / 流程图 / 指标表**之一。
- **体现 AI 特性**：必须覆盖**不确定性、评估、容错、人工介入**四个维度，不可只炫技。
- **真实用户价值**：每个功能方案都要回答"为谁、解决什么真问题、如何衡量成功"。
- **结构化工件**：01-10 每节含 12 个规定子模块（教学目标、开场问题、核心概念、产品案例演示、设计方法、PRD 模板片段、练习任务、Prompt 模板、人工检查清单、常见错误、课后作业、评分标准）。

## 六、你将带走的资产

完成本课程后，你将拥有一套可复用的产物库：
- 一份完整的 AI 产品 PRD 模板（11）
- 一个 Agent 工作流描述模板（12）
- 一张评估指标对照表（13）
- 五个可借鉴的真实形态案例（AI 客服 / 企业知识库 / 简历筛选 / 内容生成工作台 / 销售助手）（14）
- 一个 PM 版 Prompt 模板库（15）

这些不是教材，而是你下周就能在项目中直接套用的生产工具。
