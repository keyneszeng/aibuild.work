# 第 5 课  Agent 工作流

## 一、教学目标

- **知识**：理解 AI Agent 的本质——能"规划→调用工具→观察→再行动"的自主任务执行者；掌握 Agent 工作流的设计要素（任务分解、工具、人工介入点）。
- **能力**：为一款 Agent 产品画流程图（含分支、工具调用、人类审批节点）。
- **作品**：一份《Agent 流程图 + 设计说明》（可对接第 12 课 Agent 模板）。

> 本课参考 deanpeters 的 Multi-Agent 框架、minicoohei/ai-agent-camp（非工程师 Agent 训练）、Generative-AI-For-Beginners 的 Agent 章节、DataTalksClub/llm-zoomcamp 的 Agentic RAG。

## 二、开场问题

> 普通 AI 一问一答，Agent 却能"自己干完一件事"？
> 让 AI 自动发邮件、查系统，出错了谁负责？
> 哪些环节必须人点"确认"才放行？

Agent 是"会动手的 AI"。设计它的核心，是画清"它自己走哪、人在哪把关"。

## 三、核心概念

### 1. Agent 循环
规划（拆任务）→ 调工具（搜索/算数/API）→ 观察结果 → 决定下一步或结束。比单次生成多了"行动—反馈"闭环。

### 2. 工具与权限
Agent 能调什么工具、动什么系统，是产品最该收口的地方。权限越大越危险。

### 3. 人工介入点（Human-in-the-loop）
涉及发消息、花钱、删数据、对外承诺——必须人审批。这是 Agent 设计的生命线。

### 4. 失败恢复
工具报错、卡住怎么办？要有兜底路径（重试/转人工/告知用户）。

## 四、真实产品场景案例演示

### 案例：AI 销售助理 Agent
- 流程：读新线索→查 CRM→生成跟进话术→【人工确认】→发送。
- 工具：CRM 读、邮件发（发送需审批）。
- 介入点：发送前必人点确认；CRM 写入需授权。
**价值**：自动化但不失控。

## 五、动手任务

- **背景**：设计一款 Agent 产品。
- **输入**：它要完成的任务。
- **步骤**：
  1. 拆任务为 3–5 步。
  2. 标每步用到的工具与权限。
  3. 画流程图，标人工介入点。
- **预期输出**：《Agent 流程图 + 设计说明》。

## 六、Prompt / 设计模板

```
任务：[Agent 要完成的事]
请输出：①任务分解步骤 ②每步所需工具与权限 ③必须人工审批的节点 ④失败兜底方案。
用流程图文字描述（步骤→条件→分支）。
```

## 七、人工检查清单

- [ ] 任务分解合理可执行
- [ ] 工具权限最小化
- [ ] 高风险节点有审批
- [ ] 有失败兜底

## 八、常见错误

1. 给 Agent 过大权限无审批。
2. 流程图没标人工介入点。
3. 无失败恢复，卡死即崩。

## 九、课后作业

提交《Agent 流程图 + 设计说明》一份。

## 十、评分标准

- 完成度：图+说明齐全（40%）
- 质量：分解清晰、权限合理（35%）
- 安全：介入点与兜底明确（25%）
