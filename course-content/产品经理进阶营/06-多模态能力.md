# 第 6 课  多模态能力

## 一、教学目标

- **知识**：理解多模态（文本/图像/语音/视频）在 AI 产品里的落点；知道哪些场景"非多模态不可"。
- **能力**：为一个产品功能设计多模态方案（选模态、定输入输出、想边界）。
- **作品**：一份《多模态功能方案》。

> 本课参考 microsoft/AI-For-Beginners（CV/NLP/多模态章节）、Generative-AI-For-Beginners（多模态应用）、mlabonne/llm-course 的技术边界说明。

## 二、开场问题

> 用户拍张照片你就该能答，纯文本产品做不到吧？
> 语音助手为什么有时听不懂方言？
> 视频生成很酷，但你的产品真需要吗？

多模态不是炫技清单，是"用户的真实输入本来就是图/声/视频"。

## 三、核心概念

### 1. 模态 = 输入输出形态
文本、图像、语音、视频。产品要选"用户自然用什么，你就接什么"。

### 2. 典型落点
- 图像：拍图问答、OCR、识别（电商/医疗/工业）
- 语音：语音助手、转写、实时字幕
- 视频：生成口播、分析监控

### 3. 成本与体验权衡
多模态更贵、更慢（见第 8 课）。非必要不上。

### 4. 红线：隐私与合规
摄像头/麦克风涉及强隐私，需明确授权与告知。

## 四、真实产品场景案例演示

### 案例：电商"拍图找同款"
- 输入：用户拍商品图
- 处理：图像检索 + 文本生成描述
- 输出：相似商品列表
**价值**：用户自然输入是图，文本搜索反而别扭。

## 五、动手任务

- **背景**：为一功能选模态。
- **输入**：用户场景。
- **步骤**：
  1. 判断主模态（图/声/视频/文本）。
  2. 设计输入输出流。
  3. 列隐私与成本注意点。
- **预期输出**：《多模态功能方案》。

## 六、Prompt / 设计模板

```
场景：[用户怎么自然输入]
请帮我设计多模态方案：①主模态与理由 ②输入→处理→输出流 ③所需能力（识别/生成）④隐私与成本注意点。
```

## 七、人工检查清单

- [ ] 模态选择贴合用户真实输入
- [ ] 隐私授权机制明确
- [ ] 非必要未滥用多模态

## 八、常见错误

1. 为炫技强上视频生成。
2. 摄像头场景无授权告知。
3. 忽略多模态成本。

## 九、课后作业

提交《多模态功能方案》一份。

## 十、评分标准

- 完成度：方案齐全（40%）
- 质量：模态贴合、流程清晰（35%）
- 合规：隐私与成本考量（25%）
